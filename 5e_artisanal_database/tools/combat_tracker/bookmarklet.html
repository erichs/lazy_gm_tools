Player Reference Bookmarklet

This bookmarklet allows you to quickly share rules references from the 5e Artisanal Database with all players at the table by displaying them on the player-facing combat tracker page.

How to Install the Bookmarklet:

  1. Drag the button below to your browser's bookmarks bar:
📖 Send to Player View
  1. If your bookmarks bar is not visible, enable it in your browser settings
  2. The bookmarklet is now ready to use!

How to Use the Bookmarklet:

  1. Open the Combat Tracker in one browser tab
  2. Click the "Player View" button to open the player-facing page in a new tab/window (or on a separate screen)
  3. Navigate to any page in the 5e Artisanal Database that you want to share (e.g., a condition, spell, or rule)
  4. Click the "📖 Send to Player View" bookmarklet in your bookmarks bar
  5. The content will immediately appear on the player-facing page to the right of the combat tracker
  6. To clear the reference from the player view, click the "Clear Player Ref" button on the DM-facing Combat Tracker page

Example Use Case:

Scenario: A player's character becomes Restrained during combat.

  1. Navigate to the Restrained Condition page
  2. Click the "📖 Send to Player View" bookmarklet
  3. All players can now see the Restrained condition effects on the player-facing screen
  4. When no longer needed, click "Clear Player Ref" on the DM tracker

⚠️ Important Notes:

  • The bookmarklet uses localStorage, so the DM tracker and player view must be in the same browser (but can be in different tabs/windows)
  • Each new bookmarklet activation replaces the previous content (only one reference can be displayed at a time)
  • The bookmarklet automatically filters out navigation breadcrumbs and the "Markdown" link
  • This feature works best with pages from the 5e Artisanal Database, but can be used on any webpage

Technical Details:

The bookmarklet performs the following actions:

  1. Clones the current page's <body> element
  2. Removes the first <div> element (navigation breadcrumbs)
  3. Removes the first <p> element if present (Markdown link)
  4. Stores the remaining HTML in localStorage under the key playerReferenceHTML
  5. The player-facing page listens for changes to this localStorage key and displays the content

Alternative: Manual JavaScript Code

If you prefer not to use a bookmarklet, you can manually run this code in the browser console on any page you want to share:

const body = document.body;
if (!body) {
    alert('No body element found on this page.');
} else {
    const bodyClone = body.cloneNode(true);
    const firstDiv = bodyClone.querySelector('div');
    if (firstDiv) {
        firstDiv.remove();
    }
    const firstP = bodyClone.querySelector('p');
    if (firstP) {
        firstP.remove();
    }
    const filteredHTML = bodyClone.innerHTML;
    localStorage.setItem('playerReferenceHTML', filteredHTML);
    alert('Reference content sent to player view!');
}
